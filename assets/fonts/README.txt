# Science Gothic Font Files

Science Gothic is a free open-source variable font from Google Fonts.

## Download Instructions:

1. Download Science Gothic from GitHub:
   - Variable font: https://github.com/googlefonts/science-gothic/tree/main/fonts/variable
   - Or visit: https://github.com/googlefonts/science-gothic

2. Place the font file in this directory:
   - ScienceGothic-Variable.woff2 (preferred for web)
   - OR ScienceGothic-Variable.ttf (fallback)

3. The font supports variable weights (100-900) and widths (50%-200%)

## Alternative: Use Google Fonts CDN

If you prefer not to host the font files, you can add this to index.html:
<link href="https://fonts.googleapis.com/css2?family=Science+Gothic&display=swap" rel="stylesheet">

However, Science Gothic may not be available on Google Fonts CDN yet, so hosting locally is recommended.
